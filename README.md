# Travel Planner API - Backend Architecture

Descrição: API desenvolvida para o gerenciamento de roteiros de viagem, permitindo a criação, edição e consulta de destinos e datas.

Destaques Técnicos:

Desenvolvimento de rotas seguindo os princípios RESTful.

Documentação e testes rigorosos de endpoints realizados via Postman para garantir a integridade dos dados.

Tratamento de exceções e validação de entradas de usuários.

O que aprendi: Ciclo de vida de uma requisição HTTP e importância da validação de dados no Backend.
